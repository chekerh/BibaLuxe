# 3D Models Directory

Place your 3D model files (`.glb` or `.gltf` format) in this directory.

## Supported Formats
- `.glb` (recommended - binary format, smaller file size)
- `.gltf` (text-based format)

## Usage

1. Add your 3D model file to this directory (e.g., `mattress.glb`)
2. Update the product in your database with the model path:
   ```json
   {
     "model3d": "/models/mattress.glb"
   }
   ```

## Tips

- Keep file sizes under 10MB for better performance
- Optimize models before uploading (reduce polygon count if needed)
- Use `.glb` format for better compression
- Test models in the browser to ensure they load correctly
